# Math Game (C++)

A simple and well-structured C++ console game that generates math questions based on your chosen difficulty and operation type.

## Features
- **Clean Code:** Built using the Single Responsibility Principle, where every function has one specific job.
- **Customizable Gameplay:** Choose the number of questions, difficulty level (Easy, Medium, Hard, Mix), and operation type (Add, Sub, Mul, Div, Mix).
- **Interactive Console:** Shows green background for correct answers and red for wrong ones.
- **Game Summary:** Displays a final summary with your total score and Pass/Fail result.

## Built With
- **Language:** C++
- **IDE:** Visual Studio
- **Concepts:** Enums, Structs, Functions, Switch Cases, and Randomization.
