# Math Game (C++)

A simple console application for a math quiz game, built with C++.

## 🎮 Game Features
- **Custom Questions:** Choose how many questions you want to answer.
- **Difficulty Levels:** Select Easy, Medium, Hard, or a Random Mix of all levels.
- **Operation Types:** Play with Addition, Subtraction, Multiplication, Division, or a Random Mix.
- **Color & Audio Feedback:** 
  - 💚 **Green** for Right Answers
  - 🔴 **Red** with Sound Alert for Wrong Answers
- **Detailed Game Results:** Displays total questions, correct/wrong count, and overall Pass/Fail status.
- **Play Again Option:** Replay the game without restarting the app.

## 🛠️ Code & Concepts
- **Clean Code & SRP:** Built using the Single Responsibility Principle, where every function has one specific job.
- **Enums & Structs** for organized data and state management.
- **Random Generation** for dynamic number and operation creation.

## 🚀 How to Run

1. Open the project in **Visual Studio** or any C++ IDE.
2. Compile and run the `Math Game.cpp` file.
3. Follow the instructions on the screen!
